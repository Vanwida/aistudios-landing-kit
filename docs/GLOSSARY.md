# Glossary — the words, translated to Figma

| You'll hear | It means | Figma equivalent |
|---|---|---|
| Astro | The tool that turns our section files into a website | — (think: the file format of the site) |
| Section / component | One part of the page, one file | Component / section frame |
| Tokens | The named colours, sizes, spacings in one file | Variables / styles |
| CSS | The styling: colours, type, layout | The right-hand panel (Design tab) |
| HTML | The structure: headings, lists, buttons, images | Layers panel |
| Script / JavaScript | Behaviour: motion, menus, forms | Prototype interactions |
| GSAP / ScrollTrigger | The motion tools we use (scroll-driven animation) | Smart Animate, on steroids |
| Lenis | Smooth, inertial scrolling | — |
| Three.js | 3D in the browser (rarely needed) | — |
| localhost / preview / dev server | Your private preview on your computer | Prototype preview |
| Build | Packaging the files for the internet | Export |
| Save point / commit | A named version you can return to | Version history entry |
| Repo (repository) | The project's online home on GitHub | The Figma file in the cloud |
| Diff | What changed between two save points | Compare changes |
| Branch (`draft` / `main`) | A parallel copy to work in; `main` is what's live | Figma branch |
| Merge | Applying a branch to `main` | Merging a Figma branch |
| Pull request (PR) / review request | "Here's what changed, approve to make it live" | Branch review |
| Push / "saved online" | Sending save points to GitHub | Autosave to the cloud |
| Vercel | The service that publishes the site | Publish / Share prototype |
| Preview link | A URL of the latest saved-online version | Prototype link |
| Production / live | The real site on the real domain | — |
| Domain / DNS | The site's address and the settings that point it to Vercel | — |
| Breakpoint | The widths where the layout changes (768, 1024) | Frame sizes: 390 / 834 / 1440 |
| Responsive | The page works at every width | Auto layout + constraints |
| Reveal / stagger | Elements appearing on scroll, one after another | Smart animate delays |
| Parallax | Layers moving at different speeds | — |
| Pin / scrub | A section holds while scrolling drives an animation | — |
| Reduced motion | A system setting for less animation; we respect it | — |
| Console error | A problem the browser reports; Claude reads it, you don't | — |
| Alt text | A text description of an image for people who can't see it | Layer name, but for humans |
| Contrast | Text vs background legibility ratio (AA = 4.5:1) | Contrast plugin |
| OG image | The image shown when the link is shared on social/WhatsApp | Social cover |
| Lighthouse | A speed & quality score (aim ≥ 90) | — |
